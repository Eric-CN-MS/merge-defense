# Feature Specification: Merge Defense Core Game Loop

**Feature Branch**: `001-core-game-loop`
**Created**: 2026-02-25
**Status**: Draft
**Input**: 合成防御休闲游戏，参考《元气蛋蛋王》风格：拖拽合成武器、自动攻击波次敌人

---

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 合成武器 (Priority: P1)

玩家在底部格子盘上拖拽两个相同等级的武器合成，升级为更强的武器，然后在下一波敌人到来前布置好防线。

**Why this priority**: 合成是游戏的核心交互，没有合成就没有游戏。

**Independent Test**: 打开游戏，购买两个1级武器放到格子上，拖拽合并，观察是否升级为2级武器并显示正确属性。

**Acceptance Scenarios**:

1. **Given** 格子上有两个相同等级武器，**When** 玩家拖拽其中一个至另一个，**Then** 两个武器消失，合成出高一级的武器出现在同一格
2. **Given** 目标格子已有不同等级武器，**When** 玩家拖拽武器至该格，**Then** 拖拽取消，武器回到原位
3. **Given** 武器已达最高等级（5级），**When** 玩家尝试合成，**Then** 系统提示已达最高等级，无法合成
4. **Given** 格子已满，**When** 玩家尝试购买新武器，**Then** 系统提示格子已满，无法购买

---

### User Story 2 - 防御波次敌人 (Priority: P1)

格子上的武器自动攻击从屏幕上方向下移动的敌人，玩家观察战局并适时合成强化武器。

**Why this priority**: 防御是游戏目标，和合成同等重要，共同构成核心游戏循环。

**Independent Test**: 放置至少一个武器，等待第一波敌人出现，观察武器是否自动攻击并消灭敌人。

**Acceptance Scenarios**:

1. **Given** 格子上有武器，**When** 敌人进入攻击范围，**Then** 武器自动向敌人发射攻击，敌人血量减少
2. **Given** 敌人血量归零，**When** 被击败，**Then** 敌人消失，玩家获得金币奖励
3. **Given** 敌人到达屏幕底部，**When** 穿越防线，**Then** 玩家失去一条生命
4. **Given** 玩家生命归零，**When** 最后一条命失去，**Then** 游戏结束，显示本局得分与波次

---

### User Story 3 - 格子扩展与进阶 (Priority: P2)

随着游戏推进，每两关格子盘自动扩展（3×3 → 3×4 → 3×5 → ...），给玩家更多布置空间。

**Why this priority**: 进阶感是留存的关键，让玩家感受到成长。

**Independent Test**: 通过第2关，观察格子盘是否从3×3扩展为增加一列/一行。

**Acceptance Scenarios**:

1. **Given** 玩家完成第2关，**When** 进入第3关，**Then** 格子扩展一格，新格子以动画形式出现
2. **Given** 格子扩展，**When** 新格子出现，**Then** 现有武器位置不变，新格子为空可用
3. **Given** 格子达到最大尺寸（如 4×7），**When** 继续通关，**Then** 格子不再扩展

---

### User Story 4 - 英雄主角与皮肤技能 (Priority: P2)

玩家拥有一位英雄主角，可使用主动技能辅助战斗；购买皮肤可解锁不同的主角技能。

**Why this priority**: 英雄技能增加策略深度，皮肤是核心变现手段。

**Independent Test**: 选择默认皮肤进入游戏，在战斗中点击英雄技能按钮，观察技能效果是否触发。

**Acceptance Scenarios**:

1. **Given** 玩家进入游戏，**When** 游戏开始，**Then** 英雄主角显示在场景中，技能按钮可见且显示冷却状态
2. **Given** 技能冷却完毕，**When** 玩家点击技能按钮，**Then** 技能效果触发（如范围伤害、减速敌人、临时强化武器等）
3. **Given** 玩家未购买皮肤，**When** 查看皮肤商店，**Then** 可预览皮肤及对应技能描述，点击购买跳转支付
4. **Given** 玩家购买皮肤，**When** 选择该皮肤，**Then** 英雄外观变更，对应技能解锁并可使用

---

### User Story 5 - 购买武器 (Priority: P1)

玩家消耗金币从商店购买武器放入格子，为下一波做准备。

**Why this priority**: 资源管理是游戏策略层的基础。

**Independent Test**: 初始金币状态，点击购买按钮，观察金币是否扣减，武器是否出现在格子中。

**Acceptance Scenarios**:

1. **Given** 玩家有足够金币，**When** 点击购买武器，**Then** 金币扣减，1级武器放入空格（随机或指定）
2. **Given** 玩家金币不足，**When** 尝试购买武器，**Then** 购买按钮显示不可用状态，提示金币不足
3. **Given** 敌人被击败，**When** 敌人消失，**Then** 金币动画飞向金币计数器，数字增加

---

### Edge Cases

- 格子完全满时拖拽武器到边界外：武器回到原位，不丢失
- 波次进行中玩家拖拽武器：允许，武器移动后新位置立刻生效
- 多个武器同时攻击同一敌人：各自独立计算伤害，敌人血量正确累减
- 网络断开（微信小游戏）：游戏状态本地保存，重连后可继续
- 皮肤购买失败（支付异常）：不扣金币，皮肤不解锁，提示重试

---

## Requirements *(mandatory)*

### Functional Requirements

**格子系统**
- **FR-001**: 游戏开始时格子盘为 3×3，初始3个格子有随机1级武器
- **FR-002**: 每通过2关，格子盘扩展一列或一行（上限 4×7）
- **FR-003**: 玩家可拖拽格子内的武器到另一个格子进行移动

**合成系统**
- **FR-004**: 两个相同等级武器叠放时，合成为高一级武器（1→2→3→4→5级）
- **FR-005**: 5级武器为最高等级，无法继续合成
- **FR-006**: 合成时播放合成动画和音效

**战斗系统**
- **FR-007**: 敌人从屏幕上方沿 2-3 条固定路线向下移动，同一波次多条路线同时进攻
- **FR-008**: 格子上的武器自动攻击射程内最近的敌人
- **FR-009**: 不同等级武器拥有不同的攻击力、攻击速度、射程属性
- **FR-010**: 敌人有血量，受到攻击时血条减少，归零时死亡
- **FR-011**: 敌人死亡后掉落金币，金币数量与敌人强度相关
- **FR-012**: 敌人抵达底部时玩家失去一条生命（初始3条命）
- **FR-013**: 生命归零时游戏结束，显示结算界面（本局波次、最高波次记录），玩家只能选择重新开始（无复活机制）

**波次系统**
- **FR-014**: 游戏按波次推进，波次间有15秒备战时间
- **FR-015**: 每波敌人数量和强度随波次增加
- **FR-016**: 每5波出现一个Boss敌人，血量和攻击力大幅提升
- **FR-017**: 完成一波后自动进入下一波倒计时

**资源系统**
- **FR-018**: 玩家初始拥有100金币
- **FR-019**: 购买1级武器消耗固定金币（如50金币）
- **FR-020**: 金币不足时无法购买武器

**英雄系统**
- **FR-021**: 每局游戏玩家控制一位英雄主角，显示在游戏场景中
- **FR-022**: 英雄拥有一个主动技能，冷却结束后需玩家**手动点击技能按钮**触发，不自动释放
- **FR-023**: 默认皮肤提供基础技能（如范围小型爆炸）
- **FR-024**: 购买皮肤后解锁对应英雄技能（如减速光环、武器强化等）
- **FR-025**: 皮肤商店展示所有皮肤及对应技能描述和金币价格，玩家用游戏内金币购买解锁

### Key Entities

- **武器（Weapon）**: 等级（1-5）、攻击力、攻击速度、射程、格子位置
- **敌人（Enemy）**: 血量、移动速度、金币奖励、类型（普通/精英/Boss）
- **英雄（Hero）**: 当前皮肤、技能名称、技能效果、冷却时间
- **皮肤（Skin）**: 皮肤ID、名称、外观资源、解锁技能、价格（以游戏内金币计价）
- **格子盘（Grid）**: 当前尺寸、格子列表、每格状态（空/占用）
- **波次（Wave）**: 波次编号、敌人列表、敌人出生间隔
- **玩家状态（PlayerState）**: 当前金币、生命数、当前波次、历史最高波次（本地存储，微信小游戏 localStorage）

## Clarifications

### Session 2026-02-25

- Q: 英雄技能触发方式是手动点击还是自动触发？ → A: 手动点击技能按钮触发，有冷却时间
- Q: 游戏进度保存方式？ → A: 本地存储（微信小游戏 localStorage），仅存本机
- Q: 敌人路线设计？ → A: 多条固定路线（2-3条并行），玩家需覆盖多条路线布置武器
- Q: 皮肤购买货币体系？ → A: 游戏内虚拟货币（金币积累购买），无真实付费
- Q: 游戏失败后重开方式？ → A: 直接重新开始，金币/格子/武器全重置，仅保留最高波次记录

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 玩家从启动到第一波敌人出现的时间不超过30秒
- **SC-002**: 拖拽合成操作响应时间不超过100毫秒，玩家感受流畅无卡顿
- **SC-003**: 游戏在中低端安卓设备上稳定运行，帧率不低于30FPS
- **SC-004**: 新玩家无需教程即可在2分钟内理解合成和购买武器的基本操作
- **SC-005**: 一局完整游戏（到死亡）时长在3-10分钟范围内（中等难度）
- **SC-006**: 皮肤购买流程从点击到完成不超过3步操作
